# Wealth Research Desk — Website Starter

A responsive bilingual-friendly website starter made with plain HTML, CSS and JavaScript. No build tools, frameworks or paid dependencies are required.

## Files
- `index.html` — site content and sections
- `styles.css` — responsive layout and visual design
- `script.js` — working sample MCQ quiz, mobile navigation and contact email form
- `logo.png` — supplied Wealth Research Desk logo

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best results, preview on both mobile and desktop.

## Before publishing
1. The contact email is set to `kumarrakesh1999mp@gmail.com`.
2. Replace each demo video card with your real YouTube URL.
3. The supplied Wealth Research Desk logo is included as `logo.png`.
4. Review course descriptions and add links to your approved study resources.
5. Add a privacy policy and any required legal notices before collecting personal information.
6. Confirm all exam information against the latest official NISM syllabus and workbook.

## Publish for free
You can host these static files on a static hosting service such as GitHub Pages or Cloudflare Pages. A custom domain is optional and generally costs money. Hosting-provider plans and terms may change.

## Feature notes
- The sample quiz runs in the browser and does not save student progress.
- The contact form opens the visitor's email application. It does not send or store form data on a server.
- Student accounts, a secure quiz database, payment processing and an admin dashboard require a backend or third-party service; they are not included in this static starter.
- The website is an independent educational project and is not presented as an official NISM website.
